Problem #1

(Part A) Sawtooth wave

(i) Period and waveform. Successive downward jumps are two time units apart, so T=2,ω0​=π.​ A convenient definition is x(t)=t(−1≤t<1),x(t+2)=x(t). This chooses the value −1 at each jump. Any other assigned value at the jumps gives the same Fourier coefficients.

(ii) Symmetry and coefficients. Away from the jumps, x(−t)=−x(t): the waveform is real and odd. Thus its mean is zero, and its nonzero Fourier coefficients must be purely imaginary, with c−k​=−ck​.

The mean is c0​=21​∫−11​tdt=0. For a nonzero integer k, expand the exponential and use odd/even symmetry: ck​​=21​∫−11​t[cos(kπt)−jsin(kπt)]dt=−j∫01​tsin(kπt)dt.​ Integration by parts gives ∫01​tsin(kπt)dt=[−kπtcos(kπt)​+(kπ)2sin(kπt)​]01​=−kπ(−1)k​. Therefore, c0​=0,ck​=kπj(−1)k​(k=0).​ These coefficients have zero real part, as predicted. In particular, c1​=−j/π and c2​=j/(2π); these signs depend on keeping the time origin fixed.

(iii) Reconstruction and reality. Directly, c−k​=−kπj(−1)−k​=−kπj(−1)k​=ck​​. Each conjugate pair contributes a real quantity: ck​ejkω0​t+c−k​e−jkω0​t=2Re{ck​ejkω0​t}. For this waveform, xN​(t)=π2​k=1∑N​k(−1)k+1​sin(kπt).​ At every odd integer time the sum is zero, the midpoint of the jump from 1 to −1. The figures use N=3,10,50, meaning 2N+1 coefficient slots, including c0​.

(Part B) Slew-rate limited wave

(i) Period and waveform. The next rising ramp after [−2,−1] occurs on [4,5], so T=6,ω0​=3π​.​ Keeping the time origin shown in the figure, use x(t)=⎩⎨⎧​0,t+2,1,2−t,0,​−3≤t<−2,−2≤t<−1,−1≤t<1,1≤t<2,2≤t<3,​x(t+6)=x(t).​ The pieces agree at each boundary, including the periodic boundary.

(ii) Symmetry and coefficients. The waveform is real and even. Consequently, its coefficients are real and satisfy c−k​=ck​. The two unit-base triangles contribute area 1 in total and the plateau contributes area 2, giving mean 3/6=1/2: c0​=61​(21​+2+21​)=21​.​ For k=0, write α=kπ/3. Even symmetry reduces the integral to ck​=31​[∫01​cos(αt)dt+∫12​(2−t)cos(αt)dt]. The two integrals are ∫01​cos(αt)dt=αsinα​, ∫12​(2−t)cos(αt)dt​=[α(2−t)sin(αt)​−α2cos(αt)​]12​=−αsinα​+α2cosα−cos(2α)​.​ The sine terms cancel. For example, c1​=π23​,c2​=0,c3​=−3π22​,c5​=25π23​. The real, even coefficient sequence and mean agree with the symmetry and area predictions.

(iii) Reconstruction and reality. Since the formula is real and even in k, c−k​=ck​=ck​​,xN​(t)=21​+2k=1∑N​ck​cos(kπt/3).​

(Part C) Comparing the reconstructions

The sawtooth has jumps in its value and ∣ck​∣=1/(π∣k∣). The trapezoid is continuous, with jumps only in its slope; its nonzero coefficients decay as 1/k2. Thus, at the same N, the trapezoid reconstruction generally has smaller error and becomes accurate more quickly. Near a sawtooth jump, the oscillations become narrower as N increases, but the limiting overshoot is about 8.95% of the jump height, approximately 0.179 for a jump of height 2. This is the Gibbs phenomenon. The series converges to zero at the jump itself and to the waveform at each fixed continuity point. At a trapezoid corner, the value is continuous: the small rounding and ripples shrink to zero. Its 1/k2 coefficient bound gives an absolutely summable tail and uniform convergence of the signal reconstruction; there is no persistent Gibbs overshoot in its value.

(Part D) Sawtooth through an RC filter

Code for Problem 1

The accompanying Python plotting script contains all waveform definitions and plotting commands. It produces the three figures above and checks the coefficients against numerical integration of the original waveforms. The core summation is:

import numpy as np

def fourier_sum(t, N, period, coefficient):
    result = np.full_like(t, np.real(coefficient(0)), dtype=float)
    for k in range(1, N + 1):
        result += 2*np.real(coefficient(k)*np.exp(1j*k*2*np.pi*t/period))
    return result

def saw_coefficient(k):
    return 0.0 if k == 0 else 1j*(-1.0)**k/(np.pi*k)

def trapezoid_coefficient(k):
    if k == 0:
        return 0.5
    return 3*(np.cos(k*np.pi/3)-np.cos(2*k*np.pi/3))/(np.pi*k)**2

def output_coefficient(k):
    return saw_coefficient(k)/(1 + 0.5j*k*np.pi)

t = np.linspace(-2, 2, 12001)
x50 = fourier_sum(t, 50, 2, saw_coefficient)
y50 = fourier_sum(t, 50, 2, output_coefficient)

Here np is NumPy, a library for numerical arrays. np.linspace creates equally spaced times; arithmetic on the resulting array operates element by element. Python writes the imaginary unit as 1j and powers with **. range(1, N + 1) visits k=1,…,N. The factor 2Re includes both positive and negative harmonics without storing complex-valued output. Use period 6 and times from -6 to 6 for the trapezoid.

The following core calculation is included in the complete plotting script. SciPy’s step simulates the transfer function. The last out-of-band sample brackets the settling time, and brentq refines that bracket by solving a scalar equation. The theoretical envelope and later extrema establish continued settling beyond the finite simulation horizon.

import numpy as np
from scipy.signal import TransferFunction, step
from scipy.optimize import brentq

K, a = 76.25, 95.0
system = TransferFunction([100*K], [1, a+25, 25*a+100*K])
t = np.linspace(0, 0.3, 30001)
t, y = step(system, T=t)
y_final = 100*K/(25*a + 100*K)
tolerance = 0.01                    # Required 1% criterion
outside = np.flatnonzero(np.abs(y-y_final) > tolerance*abs(y_final))
last = outside[-1]                 # Python index -1 means last entry
assert last < len(t)-1             # Response has reentered the band

def exact_response(t):
    return y_final*(1-np.exp(-60*t)*(np.cos(80*t)+0.75*np.sin(80*t)))

ts = brentq(lambda t: abs(exact_response(t)-y_final)
            - tolerance*abs(y_final), t[last], t[last+1])
percent_overshoot = 100*(np.max(y)-y_final)/abs(y_final)
print(percent_overshoot, ts)

In Python, square brackets construct a list of polynomial coefficients in descending powers of s. np.abs takes elementwise absolute values; np.flatnonzero returns the indices at which the condition is true. lambda t: ... defines the one-input function passed to the root finder. The exact-response function above is specific to this chosen design.

For a unit reference, e∞​=1−y∞​=1−0.7625=0.2375.​ The output settles with a 23.75% error relative to the commanded value. Meeting the overshoot and settling-time specifications does not guarantee accurate reference tracking: both specifications here describe the transient relative to the actual final output. Indeed, even the peak 0.83477 is below the reference 1. A separate steady-state accuracy requirement would be needed to rule out this design.

Reproducing the figures and checks

Install the numerical packages in your Python environment and run the accompanying script from this directory:

python -m pip install numpy scipy matplotlib
python ps2-answers-plots.py

It saves six figures in ps2-answers-figures/. In addition to plotting, it checks the Fourier coefficients by quadrature, compares the reconstructed RC output with the independent time-domain solution, compares the simulated controller response with its exact expression, and reports the 1% settling measurement.

The separate symbolic verification script uses SymPy to check the Fourier integrals, transformed IVPs, initial conditions, differential-equation residuals, convolution transform, and block-diagram eliminations:

python -m pip install sympy
python ps2-answers-checks.py
