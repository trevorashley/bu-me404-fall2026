Problem #1: Type, Stability, and Error Constants

Source: adapted from Franklin, Powell, and Emami-Naeini, Feedback Control of Dynamic Systems, 8th ed., Problems 4.13 and 4.15 (7th ed., Problems 4.13 and 4.15).

The unity-feedback structure below applies to both parts. A disturbance W enters at the plant input; set W=0 in Part A.

(Part A) A second-order plant with a first-order compensator

Let G(s)=s2+2ζs+11​,ζ>0,Dc​(s)=s+bK(s+a)​.

(i) Ignoring stability for the moment, what constraints on K, a, and b make the closed loop Type 1 with respect to the reference? Give the velocity constant Kv​ under those constraints.

(ii) Write the closed-loop characteristic polynomial under the constraints of (i). Use Routh’s criterion to find the constraints on K, a, and b that make the closed loop both stable and Type 1.

(iii) What constraints on a and b make the closed loop Type 1 and stable for every positive value of K?

(iv) Take ζ=0.5, a=0.5, K=2, and the value of b from (i). Confirm stability, and give the steady-state error to a unit-step reference and to a unit-ramp reference.

(Part B) Satellite attitude: type depends on the input

A satellite attitude loop has plant and controller G(s)=s21​,Dc​(s)=s+510(s+2)​.

(i) Find the closed-loop characteristic polynomial and confirm by Routh’s criterion that the closed loop is stable. Report the closed-loop poles.

(ii) Find the system type with respect to the reference and the corresponding error constant. Give the steady-state error for a unit step, a unit ramp, and the parabola r(t)=t2/2.

(iii) A disturbance torque w(t) adds to the control so that the plant input is u+w. Find the transfer function E(s)/W(s), the system type with respect to the disturbance, and the corresponding error constant. Give the steady-state error for a unit-step disturbance torque.

(iv) The loop contains two integrators, yet it does not reject a constant disturbance torque. In one or two sentences, explain which integrators count for each input. See System Type, §7.2.

Problem #2: Robustness of System Type

Source: adapted from Franklin, Powell, and Emami-Naeini, Feedback Control of Dynamic Systems, 8th ed., Problem 4.21 (7th ed., Problem 4.21).

The two feedback systems below drive the same first-order plant K0​/(4s+1). System (a) uses an integral controller K1​/s. System (b) uses a proportional controller K3​ preceded by an input gain K2​. In both systems, the error is E=R−Y.

(a) Determine values of K1​, K2​, and K3​ so that, with K0​=1: (i) both systems have zero steady-state error to a unit-step reference, and (ii) both have a steady-state error of 1 to a unit-ramp reference, that is, Kv​=1 in the sense that ess​=1/Kv​ for a unit ramp. For each system, write E(s)/R(s) first and confirm that the loop is stable.

(b) Now let the plant gain change to K0​+δK0​ with the controller gains fixed at the values from (a). For each system, find the steady-state errors to a unit step and a unit ramp as functions of δK0​, and evaluate them for δK0​=0.1. Which system has a type that is robust to the change, and why? Which system would you prefer?

(c) Report the closed-loop poles of both nominal designs. Estimate the 1% settling time and the overshoot of each step response, and comment on the price that system (a) pays for its robust type. (You do not need to fix this; a later problem set will.)

Problem #3: DC Motor Position Control with Rate Feedback and Integral Action

Source: adapted from Franklin, Powell, and Emami-Naeini, Feedback Control of Dynamic Systems, 8th ed., Problem 4.25 (7th ed., Problem 4.25). The settling-time specification has been changed to the 1% criterion used in this course.

A DC motor with negligible armature inductance and a load torque w obeys θ¨m​+a1​θ˙m​=b0​va​+c0​w,a1​=65 s−1,b0​=200 rad/(V⋅s2),c0​=10 rad/(N⋅m⋅s2), where θm​ is the shaft angle in radians, va​ is the armature voltage in volts, and w is the load torque in newton-meters. A potentiometer measures the position error e=θr​−θm​, and a tachometer measures the shaft speed θ˙m​. Consider the control law va​=K(e−TD​θ˙m​), where K>0 (V/rad) and TD​>0 (s) are gains to be chosen.

(a) Draw a block diagram of the closed loop that shows both θm​ and θ˙m​ as signals. Derive the closed-loop transfer functions Θm​(s)/Θr​(s) and Θm​(s)/W(s), and note whether either has a zero.

(b) Before closing the loop, suppose a constant va​=100 V is applied with no load torque. What steady-state speed results, in rpm?

(c) Choose K and TD​ so that a step change in θr​ with w=0 produces an overshoot of at most 17% and a 1% settling time of at most 0.05 s. Show how you chose them, state whether the overshoot formula is exact for this transfer function, and report the closed-loop poles. Leave some margin on the settling-time estimate, and verify the actual settling time in part (g).

(d) Find E(s)/Θr​(s) for your design. Give the system type with respect to the reference, the velocity constant Kv​, and the steady-state error for a reference step of 1 rad and for a unit-ramp reference. How does rate feedback affect Kv​ compared with proportional control at the same K?

(e) With θr​=0, find E(s)/W(s). Give the system type with respect to the disturbance and the steady-state error for a constant load torque w=1 N⋅m.

(f) Add integral action, va​=K(e−TD​θ˙m​)+kI​∫0t​e(τ)dτ, keeping K and TD​ from part (c). Find the new characteristic polynomial and E(s)/W(s). What is the system type with respect to the disturbance now? Use Routh’s criterion to find the range of kI​ for which the closed loop is stable, and give the steady-state error to a unit-ramp load torque. Choose kI​ at one tenth of the stability limit and report the closed-loop poles.

(g) Use MATLAB to verify your design. Plot the unit-step reference response of part (c) with the 1% band marked, and report the measured overshoot and settling time. On a second figure, plot the response of θm​ to a unit-step load torque with and without integral action, and confirm the steady-state values predicted in parts (e) and (f). Use stepinfo with 'SettlingTimeThreshold',0.01 and include your code.
