Problem Set #3: Dynamic Response, Stability, and Feedback — Answer Key

This key follows the notation and diagrams in Problem Set 3. Angles are in radians, and transfer functions use zero initial conditions. For Problems 1 and 2, rise time means the first 10% to first 90% crossings of the final output, overshoot is measured relative to that final output, and settling time uses a 1% band. Numerical response specifications below are computed from the complete transfer functions.

The following MATLAB code reproduces the response plots and measurements. stepinfo receives the known final value explicitly; using the last sample as the final value would introduce an avoidable error.

s = tf('s');
gains = [0.5 1 2];
t = (0:0.002:200)';
figure; hold on
for k = gains
    T = 0.2*k/(s^2 + 0.104*s + 0.2*k);
    y = step(T,t);
    info = stepinfo(y,t,1,'RiseTimeLimits',[0.1 0.9], ...
        'SettlingTimeThreshold',0.01);
    plot(t,y,'DisplayName',sprintf('K = %g',k));
    fprintf('K = %.1f: rise = %.5f s, overshoot = %.3f%%\n', ...
        k,info.RiseTime,info.Overshoot);
end

Problem #3: Magnetic Levitation Stability

Here stability means that all internal closed-loop modes have strictly negative real parts. Assume real, finite parameters and retain the plant and controller dynamics. Set q=KK0​ to simplify the algebra.

The loop transfer function and reference-to-output transfer function are L(s)=(s+p)(s2−a2)q(s+z)​,RY​=(s+p)(s2−a2)+q(s+z)q(s+z)​. Before any pole-zero cancellation, the characteristic polynomial is Δ(s)​=(s+p)(s2−a2)+q(s+z)=s3+ps2+(q−a2)s+(qz−pa2).​​ Its Routh array is s3s2s1s0​1ppp(q−a2)−(qz−pa2)​qz−pa2​q−a2qz−pa200​=s3s2s1s0​1ppq(p−z)​qz−pa2​q−a2qz−pa200.​ Since the leading coefficient is positive, strict stability is equivalent to p>0,q(p−z)>0,qz−pa2>0.​ These inequalities also imply q−a2>0: indeed, p(q−a2)=q(p−z)+(qz−pa2)>0.

To express the conditions more directly, qz>pa2≥0 implies that q and z have the same sign. If q<0, then z<0, while p>0 would make q(p−z)<0, a contradiction. Thus q>0, z>0, and p>z. The necessary and sufficient conditions can therefore be written as p>z>0,KK0​>zpa2​.​ For the usual physical assumptions a>0 and K0​>0, this becomes 0<z<p,K>K0​zpa2​.​ The controller pole must lie farther into the left half-plane than its zero, and the gain must exceed the stated threshold. There is no upper gain bound in this ideal model. If signs of K and K0​ are not prescribed, the product condition is the appropriate statement; it requires them to have the same sign.

The inequalities must be strict. At qz=pa2, Δ(0)=0, so a mode lies at the origin. At p=z with q>a2, Δ(s)=(s+p)(s2+q−a2), which has an imaginary-axis pair. Neither boundary is asymptotically stable. Applying the test to the full characteristic polynomial also avoids incorrectly accepting a system whose unstable internal mode is hidden by cancellation in Y/R.

As a check, a=K0​=z=1, p=2, and K=3 satisfy the conditions and give Δ(s)=s3+2s2+2s+1=(s+1)(s2+s+1). Its roots are −1 and −1/2±j3​/2, all strictly in the left half-plane.

Use Ga​,Gb​,Gc​ to distinguish the overall gains of the three topologies. The feedback signals enter positive summing inputs, while each amplifier has gain −K. Writing the signal equations first keeps both signs explicit.

(a) Nominal feedback and scaling gains

A common 1% increase in the three β2​ values changes ∣Gb​∣ by approximately −2.354%, while a 1% increase in β3​ changes ∣Gc​∣ by approximately −0.99%.

Feedback reduces sensitivity to amplifier or actuator gain, but accurate output still depends on accurate feedback or sensor calibration. In the high-loop-gain limit, Gb​≈−β23​1​,Gc​≈−β3​1​. These limits explain why the sensor sensitivities approach −3 and −1 even while the sensitivities to K approach zero. For these static gain models, precision in the feedback elements is therefore more important than comparable fractional precision in the amplifier gains. Feedback cannot correct a calibration error in the measurement it uses as its reference for the output.

Reproducing the calculations

The MATLAB script requires Control System Toolbox. Run ps3_answers from its directory to plot Problems 1 and 2, print their measurements, compute both motor gain thresholds, and evaluate the nominal sensitivities. The rise-time boundary uses fzero on the analytical response; the other response measurements use step and stepinfo.

The accompanying Python verification and plotting script uses NumPy for numerical arrays, SymPy for exact symbolic algebra, and Matplotlib for figures. It verifies the partial fractions and their inverse transforms, the motor constants, the magnetic-levitation characteristic polynomial, and the sensitivity derivatives. It also compares the responses with independent numerical integration and checks that halving the numerical crossing grid preserves the reported specifications. Run it with these packages installed:

python ps3-answers-check.py

The numerical results and figures in this key were generated and checked with that Python script. The MATLAB code is supplied for course use; it was not executed in the authoring environment.
