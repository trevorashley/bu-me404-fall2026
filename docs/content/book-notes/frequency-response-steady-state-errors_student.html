Steady-State Errors from Frequency Response

Sources: Franklin, Powell, and Emami-Naeini, Feedback Control of Dynamic Systems, 8th edition, §6.1.2, Example 6.7 and Fig. 6.13; cross-checked against the 7th edition, printed pp. 330–331. Supplementary corroboration: Ogata, Modern Control Engineering, 5th edition, §7-2, printed p. 420 (reading the velocity-error constant from an extended asymptote).

Prerequisites: Bode Plot Techniques, System Type, transfer functions, the final-value theorem, and MATLAB. No Fourier transform or complex integration is needed.

Objectives: Infer Type 0 or Type 1 from the low-frequency magnitude asymptote; recover Kp​ and Kv​; and compute steady-state step or ramp error after checking stability.

Here G is the plant, Dc​ the controller, and H the sensor. The full loop is L=Dc​GH, including every gain; if a separate gain K is used, write L=KDc​GH and count it once. This note uses unity negative feedback, H=1, zero initial conditions, and reference tracking without disturbances. Then T=L/(1+L) maps reference to output and S=1/(1+L) maps reference to error. With a nonunity sensor, the physical reference response is Dc​G/(1+Dc​GH), so the unity-feedback error formulas below require reconsideration. Frequency is in rad/s and time is in seconds.

1. From the error equation to low-frequency gain

Let r be the reference, y the output, and e=r−y the tracking error. Their Laplace transforms satisfy

Y=LE,E=R−Y=R−LE,(1+L)E=R,

so

E=1+LR​=SR.

The diagram shows this disturbance-free unity-feedback interconnection.

The lower branch returns y unchanged to the minus input. This makes the controller input equal to the physical tracking error.

The final-value theorem gives

ess​=t→∞lim​e(t)=s→0lim​sE(s)

only when the relevant error transient decays: all poles of sE(s) must lie strictly in the left half-plane. Check the closed-loop interconnection as well; an unstable internal mode hidden by a cancellation is not acceptable.

As in the Bode note, for the positive-gain cases here write

L(s)∼K0​sn(s→0),∣L(jω)∣∼K0​ωn(ω→0),K0​>0.

Here n is a signed exponent, not the nonnegative system-type index used in the system-type notes: Type 0 has n=0 and Type 1 has n=−1. For these cases, type equals −n. Each uncanceled integrator contributes a factor 1/s and lowers the low-frequency slope by 20 dB/decade.

Watch out: Large low-frequency gain predicts small steady-state error only for a stable closed loop. The final-value theorem does not turn an unstable response into a finite error.

2. Type 0 and the position-error constant

For Type 0, L(s)→K0​ as s→0. A unit step has R=1/s, so, under the preceding stability assumptions,

ess​=s→0lim​s[1+L(s)]s​=1+Kp​1​,Kp​=s→0lim​L(s)=K0​.

The horizontal low-frequency asymptote therefore gives the position-error constant Kp​ in linear magnitude. If its height is B dB relative to unit loop magnitude,

B=20log10​Kp​,Kp​=10B/20,ess​=1+10B/201​.

The symbolic sketch connects the horizontal line to the step-error formula without introducing another numerical example.

A higher horizontal line means a smaller step error under the stated positive-gain convention. A magnitude plot alone cannot identify a negative DC sign: it gives ∣L(0)∣, whereas Kp​=L(0) includes the sign.

3. Type 1 and the velocity-error constant

For Type 1,

L(s)∼sKv​​,Kv​=s→0lim​sL(s).

For a unit step, multiply numerator and denominator by s to obtain

ess​=s→0lim​1+L(s)1​=s→0lim​s+sL(s)s​=0.

For a unit ramp, r(t)=t and R=1/s2, giving

ess​=s→0lim​s[1+L(s)]1​=s→0lim​s+sL(s)1​=Kv​1​.

The low-frequency magnitude asymptote A(ω) obeys

A(ω)=ωKv​​,Kv​=ωA(ω).

At 1 rad/s, the asymptote’s numerical magnitude equals the numerical value of Kv​ when seconds are the time unit. Kv​ has units s−1; radians are dimensionless. More generally, if B(ω)=20log10​A(ω),

Kv​=ω10B(ω)/20.

Extend the initial low-frequency line to 1 rad/s if necessary, even if a break has already occurred. A post-break composite magnitude is not the required asymptote. For a ramp with slope v in output units per second, r(t)=vt, linearity gives ess​=v/Kv​ in output units. The unit ramp has slope one output unit per second.

Connection: The low-frequency Bode slope counts the integrators contributing to tracking accuracy. It is the frequency-domain version of the limits in the system-type notes, which also treat Type 2.

4. Example 6.7: both readings of the same asymptote

FPE Fig. 6.13 specifies the full loop

L(s)=s(s+1)10​,L(jω)=jω(1+jω)10​,M(ω)=∣L(jω)∣=ω1+ω2​10​.

The low-frequency line is A(ω)=10/ω, with slope −20 dB/decade, so this is Type 1. Read the same constant in either of FPE’s two ways:

A(1)=10⇒Kv​=1(10)=10 s−1,

A(0.01)=1000⇒Kv​=0.01(1000)=10 s−1.

Thus the unit-ramp error will be 1/Kv​=0.1 if the closed loop is stable. The exact curve gives different readings:

M(0.01)=0.011.0001​10​≈999.9500,M(1)=2​10​≈7.07107.

The printed curved trace in both editions is not a quantitative benchmark for the caption model; the exact curve below is recomputed from that model. The reconstruction distinguishes the exact curve from the extended low-frequency line in FPE Fig. 6.13.

At 0.01 rad/s, the exact curve almost coincides with the asymptote. At the 1 rad/s break, their separation is visible: the asymptote gives 10 and the exact curve gives 7.07107.

Don’t make this mistake: Reading 7.07 from the exact curve at 1 rad/s gives the wrong Kv​. Use the extrapolated low-frequency line or the limit lims→0​sL(s).

Before using the final-value theorem, compute the closed-loop transfer function and poles:

T(s)=1+LL​=s2+s+1010​,s2+s+10=(s+1/2)2+39/4,

p=−21​±j239​​.

Both poles lie strictly in the left half-plane. There are no hidden unstable cancellations in this model. For a unit ramp, use the error path S, not the output path T:

S(s)=s2+s+10s(s+1)​,E(s)=S(s)s21​=s(s2+s+10)s+1​.

Partial fractions give

E(s)=s0.1​+s2+s+10−0.1s+0.9​.

Indeed, clearing denominators recovers 0.1(s2+s+10)+s(−0.1s+0.9)=s+1. Complete the square, s2+s+10=(s+1/2)2+39/4, and rewrite the numerator as −0.1(s+1/2)+0.95.

With ωd​=39​/2,

E(s)=s0.1​−0.1(s+1/2)2+ωd2​s+1/2​+(s+1/2)2+ωd2​0.95​.

The Laplace pairs for a decaying cosine and sine are

L{e−atcosbt}=(s+a)2+b2s+a​,L{e−atsinbt}=(s+a)2+b2b​.

Applying them term by term gives the complete zero-initial-condition error,

e(t)=0.1+e−t/2[−0.1cos(ωd​t)+ωd​0.95​sin(ωd​t)].

Both transient terms decay, so e(t)→0.1, also obtained from lims→0​sE(s)=1/10. The error history shows the oscillation that the final-value calculation omits.

The error initially equals zero, oscillates about 0.1, and settles to the nonzero ramp separation. Zero step error does not imply zero ramp error.

Use the accompanying MATLAB demonstration to reproduce the figures and numerical comparison:

s = tf('s');
L = 10/(s*(s+1));
T = feedback(L,1);              % reference -> output
S = feedback(1,L);              % reference -> error
pole(T)                         % check stability first
Kv = dcgain(minreal(s*L));       % limit of s*L = 10/(s+1)
t = (0:0.002:30)';
r = t;
e = lsim(S,r,t);
plot(t,e); grid on
xlabel('Time (s)'); ylabel('Tracking error (output units)');

Here minreal(s*L) removes the known algebraic factor at the origin in the expression sL to evaluate a mathematical limit. It is not a physically implemented pole cancellation or a substitute for the closed-loop stability check. dcgain(L) is infinite and does not compute Kv​.

5. Design implication

Multiplying the full loop by a positive factor β adds 20log10​β dB to its magnitude and multiplies its error constants by β. If stability is retained, the Type 0 unit-step error becomes 1/(1+βKp​) and the Type 1 unit-ramp error becomes 1/(βKv​).

For this particular loop, the characteristic equation becomes s2+s+10β=0. For β>0, its roots [−1±1−40β​]/2 are both negative when real, or have real part −1/2 when complex. Thus all positive scalar gains preserve stability here. This is not a general guarantee. The following material on Neutral Stability and Compensation examines why increased gain can threaten stability in other loops.

Takeaway: Read the initial low-frequency asymptote to recover the error constant, then check stability before translating that constant into a steady-state error.
